# Legal Basis Finder (법적 근거 탐색기)

한국법 사건의 **사실관계를 입력하면 → 법적 쟁점 도출 → 적용 법조항·판례를 웹 검색으로 실제 확인 → 준비서면·내용증명에 바로 쓸 근거**까지 한 흐름으로 정리해 주는 Claude 스킬입니다.

법률사무소에서 사건마다 반복되는 작업(쟁점 잡기, 조문 찾기, 유사 판례 찾기, 근거 정리)을 매번 처음부터 하지 않도록 한 번에 묶었습니다.

## 무엇을 해주나요

사건 사실관계를 던지면 아래 5단계로 정리해 줍니다.

1. 사실관계 정리 (시간순·당사자별)
2. 법적 쟁점 도출 (상대방이 들고 나올 쟁점 포함)
3. 적용 법조항 확인 (국가법령정보센터 등 공식 소스 우선)
4. 유사 판례 확인 (대법원 판례 우선, 공식 소스에서 검증)
5. 근거 정리 — **(a) 쟁점별 메모**와 **(b) 준비서면·내용증명에 바로 붙일 인용 문구** 두 가지

## 핵심 특징: 인용을 지어내지 않습니다

법률 AI에서 가장 위험한 건 존재하지 않는 판례번호를 그럴듯하게 만들어내는 것입니다. 이 스킬은 그것을 막기 위해 만들어졌습니다.

- 판례번호·법조항을 기억으로 적지 않고 **웹 검색으로 실제 확인**한 뒤에만 인용합니다.
- 확인된 인용에는 `✅검증` 표시와 출처 링크를 답니다.
- 확인하지 못한 항목은 `⚠️ 미검증`으로 표시하고, 인용 문구에는 넣지 않습니다.

## 설치 방법 (Claude Code 기준)

이 스킬은 웹 검색만 사용하므로, 받자마자 별도 설정 없이 바로 작동합니다.

**방법 A — `.skill` 파일로 설치**

1. 이 저장소의 `legal-basis-finder.skill` 파일을 내려받습니다.
2. 터미널에서 스킬 폴더에 압축을 풉니다:
   ```bash
   unzip -o legal-basis-finder.skill -d ~/.claude/skills/
   ```
3. Claude Code 세션을 새로 시작합니다.

**방법 B — 저장소를 통째로 받아 폴더만 복사**

1. 이 저장소를 클론하거나 ZIP으로 내려받습니다:
   ```bash
   git clone <이 저장소 주소>
   ```
2. `legal-basis-finder` 폴더를 스킬 폴더로 복사합니다:
   ```bash
   cp -r legal-basis-finder ~/.claude/skills/
   ```
3. Claude Code 세션을 새로 시작합니다.

설치 확인:
```bash
ls ~/.claude/skills/legal-basis-finder/   # SKILL.md 가 보이면 정상
```
※ 폴더가 한 단계 더 깊이 중첩되면 인식되지 않습니다. `~/.claude/skills/legal-basis-finder/SKILL.md` 구조여야 합니다.

## 사용 방법

설치 후 Claude Code에 사건 사실관계를 그대로 입력하면 됩니다. `/legal-basis-finder`로 직접 부를 수도 있고, 사건 검토 맥락이면 자동으로 발동됩니다.

예시:
```
임차인인데 계약 끝나고 2개월째 보증금 5천만원을 못 받고 있어.
임대인은 새 세입자 들어오면 준다고만 해.
어떤 법적 근거로 압박할 수 있고 준비서면에 넣을 문구까지 정리해줘.
```

## ⚠️ 사용 시 반드시 지켜야 할 것

- 이 스킬의 결과는 **1차 검토를 빠르게 돕는 참고자료**이지, 검증이 끝난 최종 근거가 아닙니다.
- `✅검증` 표시가 붙은 인용이라도, **준비서면·내용증명에 실제로 넣기 전에는 사람이 판례 원문을 직접 확인**해야 합니다. (AI가 검색 결과를 잘못 읽거나 판시 취지를 미묘하게 과장할 여지가 남아 있습니다.)
- 최종 판단과 소송 전략은 담당 변호사의 검토를 반드시 거쳐야 합니다.
- 한국법 기준입니다. 외국법 사안에는 적합하지 않습니다.
